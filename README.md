# 🇨🇦 Canada Population Dashboard

An interactive data visualization application built with **Streamlit**. This project analyzes quarterly population trends in Canada, demonstrating skills in data processing and web application development for data science.

## 🎯 Overview
This tool allows users to explore Canada's population growth over time through dynamic charts and data tables. It serves as a practical example of how to transform raw CSV data into an insightful, user-friendly dashboard.

## 🛠️ Tech Stack
- **Python**: Core programming language.
- **Streamlit**: Framework for building the web interface.
- **Pandas**: For data manipulation and cleaning.
- **Matplotlib / NumPy**: used for data calculation and plotting.

## 📂 Project Structure
- `canada_pop.py`: The main application script containing the Streamlit logic.
- `quarterly_canada_population.csv`: The dataset containing historical population records.
